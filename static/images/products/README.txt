Every product already has a drawn picture in this folder (the .svg files).

To use your own photo instead, save it here with the SAME name but a .jpg, .png or .webp ending,
for example:  ultratech.jpg   maha-hd.jpg   tmt-bar-12-mm.jpg
The photo automatically replaces the drawing. Delete the photo to go back to the drawing.
